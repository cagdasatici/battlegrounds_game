## Notes on equivalence
- Input channel `drain()` (queue) and `expireLease()` (held) touch different fields, so draining first then clearing leases is equivalent.
- Locomotion intents are now computed after all seats finished their action transitions, not interleaved per seat. This differs
  only if one seat's skill start mutated another seat's action state, which no current handler does. Not separately tested.
- Hit and KO events keep per-result order (hit event, then KO for that result) inside `deathsAndRespawns`. Respawn is T17.
