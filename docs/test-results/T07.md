## How checks were run
The main checkout could not `pnpm install --frozen-lockfile` because a concurrent T05 edit adds
`@dimforge/rapier3d-compat` to `apps/server/package.json` without a lockfile update. To avoid touching
the lockfile, checks ran in a detached git worktree of HEAD 7999339 plus the T07 files copied in
(identical content), with `pnpm install --frozen-lockfile` succeeding there. Stale committed
`*.tsbuildinfo` files caused TS6305 errors on a fresh worktree; after deleting them in the worktree only,
`tsc -b` passed.

## Coverage in tests/unit/touch-shell.test.ts
- Layout fixture: 1024x768 centres for attack, jump, dash, block and skills 1-4 match section 7 exactly.
- D01 simulated: 1024x768, 1180x820, 1180x776 with 24 px top inset, 1366x1024, 800x600, 700x420:
  no control outside safe rect, no hit target below 48 px, every pair >= 8 px apart.
- Scale clamp 0.78..1.25; too-small flag for W<700 or H<420; validator detects overlap/outside.
- Precedence button -> joystick -> camera; display-only health bar is not a target.
- Five simultaneous pointers independent; camera release keeps move and attack.
- Captured pointer moving over another button does not activate it; release outside sends skillUp.
- First pointer wins a hold control; extra pointer cannot release it.
- Guard suppresses attackHeld; held Jump yields one edge; duplicate pointerdown ignored.
- Joystick 10s dead zone and 56s cap; pitch clamp -55 deg.
- Cancel releases charge without skillUp; awakening edge only when meter full; facing toggle.
- Menu, releaseAll and layout change: neutral intent, no inherited pointers, input disabled when too small.
- IntentSampler packets parse with shared `parseInputPacket`; unique edge ids; max 6 edges per packet
  with overflow carried; epoch change drops queued edges.
- DOM binding with a real `EventTarget`: capture, blur, visibilitychange, lostpointercapture,
  cleanup removes listeners, releases captures and restores touch-action.
- Hud model: boxes follow layout, rotate and enlarge panels, awaken ready only at full meter.
