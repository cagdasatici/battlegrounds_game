# T18c test report (app flow, lobby and HUD)

Date: 2026-11-01. Node v22.23.4 (repo wants 24.22.2; engine WARN only).

## What changed
- `apps/client/src/app/AppFlow.ts` (new): state machine boot, welcome, lobby, match, error. Five error states plus UNSUPPORTED
  (WebGL2/WebAssembly missing, with Retry, no join request). ROOM_FULL, SERVER_OFFLINE, ASSET_FAILED, UNSUPPORTED offer Retry;
  INVITE_INVALID and VERSION_MISMATCH offer Back only (never loops invitations). Retry delay 0.5, 1, 2, 4, 8 s cap; login is
  never repeated once it succeeded; no invitation in the URL means Play shows INVITE_INVALID without any request.
- `apps/client/src/ui/Lobby.ts` (new): Welcome (Play, connection status, Arel/Nora name labels only), lobby (room status
  "N of 4", only P0 kits via `P0_KITS`, four base move labels, awakening overview line, Ready, Back), error screens with plain
  text. One delegated click listener, removed in dispose().
- `apps/client/src/ui/HudFormat.ts` (new, pure): cooldown label (one decimal under 10 s, ceiling seconds from 10 s, from
  `cooldownEndTicks` minus estimated server tick), rejection text (STATE Recovering, COOLDOWN Cooling down, METER Need full
  meter, else Cannot use now; 0.7 s, one message per window), respawn seconds (180 ticks), scoreboard rows, meter percent
  threshold normalized or "Ready", form timer, Stillpoint remaining (owner-only field).
- `apps/client/src/ui/Hud.ts`: skill boxes show cooldowns, HP bar fill, Awaken shows percent or Ready, overlays for form and
  Stillpoint, rejection toast, death/respawn countdown with scorer, scoreboard (control tap), kit choice panel (Fighter
  control, sends `changeKit`, intent only), Menu panel ("The arena continues while this menu is open.", Leave).
- `apps/client/src/main.ts`: rewritten around AppFlow. Match resources have their own cleanup list so Leave returns to
  Welcome and closes the room; page-level cleanup on pagehide. `?auto=1` presses Play and Ready (browser tests).
- Bug fixed on the way: awakening readiness and the HUD used `meter100 / 10000`; now `meterFraction(kit, meter100)`
  (threshold 20000 for sv, 35000 otherwise).
- `playwright.config.ts`: `workers: 1`. Two specs in parallel starved the in-process tick loop and the server then
  refused a join as overloaded (ROOM_FULL) in match.spec.ts.
- `tests/browser/match.spec.ts`: URL gains `&auto=1` (the flow now starts at Welcome).
