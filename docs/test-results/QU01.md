## Changes
- Sparring and score actions are separate measured rectangles: new `placeSparringRect` (ControlLayout.ts) scans the top rows right to left for a spot at least 8 px from every control hit target (after layout edit too, because it reads the resolved layout). main.ts places the host's sparring button with it during a match and hides it if nothing fits rather than overlapping. Before: the button was fixed at right 16 px, top 16 px and sat on top of the Score control.
- Skill buttons show the equipped short name plus readiness as text ("1 Fault Strike / Ready", "2 Undertow / 3.2") and as shape (solid thick border when ready, dashed thin and dimmed when cooling). Names follow the current form (Base or Awakened).
- Block feedback: the Guard button turns gold and reads "Blocked!" and a "Blocked!" badge shows for 0.8 s, only after a server "block" combat event targeting the local player (`BlockNotice`). Holding Guard alone never shows it.
- Guide: first lines of both Touch and Keyboard lists are the exact prompts Move, Aim, Strike, Guard, Use a skill with their bindings; the existing binding lines are kept. Practice progression untouched.
