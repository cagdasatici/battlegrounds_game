## A — First match without coaching

Give each player only: “Join the same room, use a skill, block an attack, and
play a second round together.” Allow five minutes without coaching, then swap
host and guest and repeat. Each player must complete all four actions unaided.
Partial completion fails the usability gate; record it without replacing it
with a coached retry.

defender views), and five audio samples (three elements, block, counter).
