## Fixture

Two isolated browser contexts with ordinary sessions or a scoped sparring guest. Invite tokens are local test-only values minted in-process; no token, link or session id is written here. The test clock offsets only link and sparring-directory deadlines.

## Defect found and fixed
The release CSP (`style-src 'self'`) blocked the inline `<style>` elements created by How to play and Sparring setup. The Vite dev server sends no CSP, so no earlier browser test saw it; on the production build those two screens lost their styling (Chromium logged "Applying inline style violates ... style-src 'self'"). Fixed at the shared cause with `apps/client/src/ui/adoptCss.ts` (constructed stylesheet, removed on dispose), used by both screens. The CSP is unchanged. Every QW01 context now fails on any CSP console message. Decision 0045.

## Coverage (5 tests, all passed)
1. Cold install: worker controls the page, precache more than 25 entries, no `/api`, `/healthz`, `/matchmake` or `/admin` in any cache, `/api/admin/status` refuses a player (401, 403 or 404), `/admin.html` is `no-store`; offline reload shows the plain "cannot reach the game" state with Retry; back online Retry gives the plain invitation message.
2. Signed-in list and one-tap join: two clients join the arena room from the list (second sees "Play: 1 of 4 players"), both reach Ready, probe shows two players; a listed four-fighter sparring match is a disabled "Full" row.
3. Scoped guest: no ordinary session cookie, guest cookie set, fragment removed from the URL. Server drops the guest socket during combat: seat retained, no duplicate fighter, HP not restored, client reconnects inside the window. KO read identically by both clients. Host ends the match, guest returns to Welcome, new match has a new code and zero kills, deaths and full HP for both.
4. Expiry: an expired guest link gives 401 INVITE_INVALID with no guest cookie; a guest seat whose device cannot return is freed after the 20 s window.
5. Update: a build published on Welcome is offered; joining a practice room removes the button and causes no navigation; after Leave the button returns; a tap swaps the cache to the new build.
