## Changed
- `AppFlow.runEarly` (Practice): pick screen at once; assets, sign-in and join run in parallel (`allSettled`); Ready before completion is queued (`pendingReady`, "Almost ready…") and sent when joined; failure leaves any joined room and shows the existing error with Retry; Back bumps the revision, leaves, and waits for the run to release its room; `ensureAssets` is a shared promise; `warm()`; `hostSparring` loads assets and signs in in parallel.
- `Lobby`: pressed Welcome button gets `aria-busy` and "Preparing…" in the click handler, other entry buttons `disabled` + `aria-disabled`; `releasePressed()` when the Fight bots setup closes or fails.
- `main.ts`: opening Fight bots warms assets; at idle (`requestIdleCallback`, timeout fallback) the runtime chunk and map file are preloaded (no renderer).
