## Limitations
- No ability ships yet, so there is no over-the-wire ability test; the first real-client network test lands with T12.
- `turnRate` facing lock is not enforced in Movement; hits use the aim yaw snapshot taken at commit, so only visuals could differ.
- holdRelease, recast and context inputs are rejected as INVALID until T19 and T23.
- `armor: "onHit"` is read as armored through startup and active (D, not in the spec); revisit if a card needs different timing.
- Repo hygiene: `tsconfig.tsbuildinfo` files are tracked while `dist/` is ignored, so a fresh checkout fails `tsc -b` with TS6305 until they are deleted. Not changed here.
