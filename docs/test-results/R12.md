Date: 2026-11-01. Branch wave3-r12 on 2256eec. File: tests/integration/kit-matrix.test.ts (port 25710). No production code changed.

## Method
Two real RoomClient connections per row. Seat A casts through PointerRouter + IntentSampler (skill/awaken edges only). Seat B is
the victim. Both clients record [caster, victim] state per replicated `serverTick`. Per row: (1) every serverTick both clients
share after the edge has identical state; (2) at the first common tick >= edge tick + waitTicks, victim hp100 and action match the
spec-derived expectation; (3) the combat event streams received by both clients are equal; (4) server invariantViolations is empty.
Server objects are used only for fixtures (placement through the body API, meter pre-fill), as in the other integration tests.
Deviation from the packet shape: Row has extra `casterKit/victimKit`, `after` (victim attacks into a counter stance), `expectCasterForm`
and `check`; edge ticks are taken from the replicated serverTick at tap time.
