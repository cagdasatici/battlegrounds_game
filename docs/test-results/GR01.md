## Flake fix 2026-11-04

Symptom: "admin revoke closes only the revoked seat with 4401 ..." timed out at `waitFor "A removed"` (20 s) under load; passes alone.
Reproduced: 6 concurrent runs of the file plus CPU burners failed 4 of 6, always at "A removed" (the 4401 close itself was observed).
Root cause (product race, not test timing): `revokeAuthSession` calls `client.leave(4401)`; if the socket close reaches the server as an ordinary drop, `ArenaRoom.onDrop` created a 20 s reconnect reservation for the already revoked session, so the ghost fighter stayed seated for the full reservation.
Fix (`fix(auth)`): `onDrop` returns before reserving when `seatSessionValid(seat)` is false, so Colyseus calls `onLeave` immediately. New deterministic regression test "a socket drop after the session is revoked never reserves the seat" (suppresses the revoke close, revokes, drops the socket; failed before the fix, passes after). Also widened the bounded "fighter removed" wait in the reconnect-recheck test from 3 s to 20 s (it failed once under 25-process load).
Counts: pre-fix 4/6 failed under concurrent load. Post-fix: 20 concurrent file runs + full suite + CPU burners: 20/20 revoke test passes (2 failures were the 3 s wait above, since widened); 20 sequential file runs while `pnpm test` ran in the background: 20/20 pass (7 tests each). Typecheck and lint pass. Final full `pnpm test`: 1911 passed, 1 failed (`practice-drills` GR15b "wrong facing and late guard...", unrelated; it also failed in the pre-fix full run), so the full suite is not green.
