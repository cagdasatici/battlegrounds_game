# Q01 — Reproducible fight and frame captures

Base SHA 3c61243. Node 24.22.2, pnpm 10.28.0 (from $HOME/.local/node24/bin), macOS arm64, 2 November 2026.

## What was added
- `tests/browser/harness/quality-metrics.ts`: nearest-rank percentile, frame statistics (median FPS from the median interval, p95 by nearest rank, longest run of consecutive intervals above 33.3 ms), explicit setup/hidden/teardown exclusion with omitted seconds reported, six-event validity check and the run-record shape from the plan. Empty runs return null metrics with a reason.
- `tests/unit/quality-metrics.test.ts`: nearest rank, slow interval, empty run, hidden sample, missing events.
- `tests/browser/quality-fight.spec.ts`: one ordinary host (Tide Duelist), one human-equivalent guest (Ember Artificer) through the sparring guest link, and two legal server bots (Easy, Medium) on the main island. Smoke runs one cycle; `EB_QUALITY_LONG=1` repeats cycles for `EB_QUALITY_MINUTES` (default 5; set 10 for the ten-minute run). Long mode is **NOT RUN**.
- Opt-in debug probe in `apps/client/src/main.ts` (only under `?debug=1`): `eventCounts` by combat-event kind and `render` {calls, triangles, effective tier} read from `renderer.info` after completed renders. Absent on normal sessions. No `art.ts` extension was needed; the Q00 camera fixtures are recorded in `docs/test-results/Q00/static-fixtures.json`.

## Workload and setup labels
Dev client, desktop Chromium on SwiftShader (diagnostic only, not a device). Synthetic server fixtures: spawn positions, awakening meter, HP and one orb spawn plus reflection through the shipped projectile system. Real input: Awaken (G), dash (Q), guard (F) and held Attack by touch/mouse on the HUD control. Server outcomes only; both clients must agree on every fighter's HP at the end.

## Smoke result (docs/test-results/Q01/smoke-low-run.json)
Events: overlapping awakened fighters 1, hit 28, block 1, dash 1, reflection 1, KO 1. Effective tier low (software pins low). 150 frame samples over 10.3 s after excluding 11.96 s setup, 0.08 s teardown, 0 s hidden. Median 15.0 FPS, p95 116.7 ms, longest slow run 3.15 s: SwiftShader CPU rendering, not a quality signal. Max 41 draw calls, 91,524 visible triangles (renderer.info). Heap fields are null with a stated reason.
