# GR15c decision: leave-the-warning practice lesson

- Wire: no new message and no new owner field. Only the existing `practiceDrill` enum gains `evade`; owner `drillState` gains the value `failed` (string field). `PROTOCOL_VERSION` stays 4.
- Dummy: Stone Vanguard (`kitId` "sv") for this lesson only, using the existing `sv.b1` with no data override, enlarged warning or slower timing. Cast: one ordinary slot 1 `skillDown` edge queued through the temporary `drill:dummy` pipeline seat on tick start+120 (integer ticks). Exit (and the block lesson) restores the ordinary practice Tide Duelist and home (0,-1).
- Judging: bound at the dummy's windup from `AbilityRunner.castOf` (cast counter, activeStart/End, aimYaw). Inside = `inFaultStrikeFootprint` (the ability's own `shapeOverlaps` for the direct box plus the 8 m wave box, wave excluded for ragdolled targets). Success needs: inside when windup began, protection/invulnerability absent, outside every applicable footprint at the first active tick, and no resolved result from that cast (hit, blocked, countered, captured, protected, invulnerable...) in the active window. Success is set on the last active tick. A touch, a protected start or an outside start sets `failed` at once. No automatic repeat; Retry builds a new trial object and re-resets both fighters.
- Cancel: player or dummy death, player leave, player or dummy kit change voids the trial (state stays `running`, Retry/Exit remain; no success, no failure).
- Authority conflict recorded: spec places the dummy at (0,0). As with GR15a/GR15b that point is a seam or raised collider. The lesson is staged with the block lesson's level floor: dummy (2,-1), player (2,1), exactly the specified 2 m gap, facing +z. Sideways exit toward +x or -x is level.
- Copy: spec strings. Label `Leave the warning` collides with `/leave/i` role selectors only in practice.spec.ts (expanded panel); that selector was made exact.
